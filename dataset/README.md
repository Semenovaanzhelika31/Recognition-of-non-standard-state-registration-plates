# Датасет нестандартных ГРЗ РФ (тип 1А — квадратные, тип 1Б — жёлтые) — датащит

Полуфинал «Искусственный интеллект и анализ данных» (куратор — АИС Город). Лицензия — CC BY 4.0 (см. `LICENSE`).

## Состав и структура
```
dataset/
  images/real/        реальные изображения — пуста (датасет полностью синтетический, см. ниже)
  images/synthetic/   5000 синтетических изображений (генерируются скриптом, seed зафиксирован)
  labels/             по одному .txt на изображение
  meta.csv            одна строка на знак, разделитель ';'
  generator/          генератор синтетики, шрифты, requirements.txt
  README.md, LICENSE, validation_report.md
```
**Состав: датасет полностью синтетический.** ТЗ допускает «собрать и/или сгенерировать», поэтому реальные снимки не
собирались (`images/real/` оставлена пустой по структуре из ТЗ). Рекомендованные в ТЗ объёмы реальной части (type1a ≥150 изобр./≥50 номеров,
type1b ≥300/≥100, other ≥50) **не набирались**; это отражено в `validation_report.md` информационной строкой. Автоматическая
разметка чужой моделью в датасет не включалась. Для пополнения реальными данными есть `tools/annotate.py`
(ручная разметка с размытием лиц) и `tools/validate_dataset.py`.

**Внешние данные вне датасета.** Распознаватель символов решения дообучен на реальных вырезках из набора Kaggle
«Russian License Plate Characters — 23 Classes» (автор dimahkiin, CC BY 4.0, раздел val). Эти данные в датасет не входят;
их разметка сделана автором моделью, поэтому они не выдаются за ручную разметку участника.

## Формат
`meta.csv` (разделитель `;`, UTF-8): `image; plate_num; plate_type; bbox; quad; is_vehicle; is_synthetic; source; license; conditions`.
* `plate_num` — A123BC456 / A123BC45, латиница в верхнем регистре, `#` — нечитаемая позиция; для `other` — `#`;
* `plate_type` — `type1`, `type1a`, `type1b`, `other`;
* `bbox` — `x,y,w,h` в пикселях; `quad` — `x1,y1,...,x4,y4` по часовой стрелке от левого верхнего угла знака;
* `is_vehicle` — 1 знак на транспортном средстве, 0 — щит/витрина/экран (в синтетике ≈12% знаков на щитах);
* `conditions` — через запятую из `day, night, rain, snow, dirt, glare, motion_blur, angle` (условия кадра, одинаковые для всех знаков кадра).

`labels/<имя>.txt`: по строке на знак `cls cx cy w h x1 y1 x2 y2 x3 y3 x4 y4`, координаты нормированы на размер
кадра; `cls`: 0 type1, 1 type1a, 2 type1b, 3 other. **Формат txt-меток в тексте ТЗ не определён**, выбран
YOLO-совместимый с четырьмя угловыми точками; при появлении валидатора организаторов его нужно сверить.

## Методика синтетики (`generator/`)
1. **Знак.** `gostplate.py` рисует знаки типов 1, 1А, 1Б по габаритам из ТЗ (520×112 и 290×170 мм) и маске
   «буква, 3 цифры, 2 буквы, регион 2–3 цифры» (допустимые буквы A B E K M H O P C T Y X). Размеры символов,
   интервалы и блок региона/RUS/флаг оценены по виду знаков и **приближают, но не копируют** ГОСТ Р 50577-2018;
   шрифты свободные, форма глифов отличается от эталонной. Случайные: шрифт (4), ширина и толщина штриха, фон (жёлтый
   — для 1Б), рамка, наличие RUS. Коды регионов — 2-значные 01–99 и набор типичных 3-значных.
2. **Негативы (`other`).** Прицеп (иная маска), мотоцикл, дипломатический (красный), военный (иная маска), европейский
   (синяя полоса), американский, «белорусский» (иная маска), транзит; плюс знаки на рекламных щитах (`is_vehicle=0`),
   кадры без знаков, случайные надписи и вывески как «ложные символы».
3. **Сцена.** Фон (градиент, кирпич, полосы, текстуры), схематичный автомобиль (кузов, стекло, бампер, фары/решётка,
   колёса, посадочное место) или щит. Плоскость с объектом проецируется камерой (рыскание до ±58°, тангаж до ±20°,
   крен до ±12°, размер знака 42–560 px по ширине); метки берутся из той же гомографии.
4. **Условия.** Ночь (подсветка зоны знака), дождь, снег, блики, грязь на знаке, смаз, расфокус, потеря разрешения, шум,
   JPEG 60–95. Теги пишутся в `conditions`.
5. **Воспроизводимость.** `python generator/generate_synthetic.py --out . --n 5000 --seed 20261014 --meta meta.csv` (из корня датасета; на слабой машине используйте `--workers 1`); i-е изображение
   строится из `SeedSequence([seed, i])`, поэтому результат не зависит от числа процессов.

## Ограничения (честно)
* Синтетические автомобили и фоны схематичны; разрыв доменов с реальными кадрами значителен. Качество на реальных
  знаках type1a и type1b **не измерялось** — собственных реальных данных нет.
* Геометрия знаков приближённая (см. выше).
* Статистика по условиям съёмки — по кадру, а не по знаку.
* Отладочный набор организаторов (30 изображений) в датасет **не включался** и не использовался.

## Проверка
`python tools/validate_dataset.py --root dataset --report dataset/validation_report.md`
(собственный валидатор формата; валидатор организаторов недоступен — его отчёт нужно приложить отдельно).
